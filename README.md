# LAN Share

เว็บแอปพลิเคชันสำหรับแชร์ไฟล์ภายในเครือข่าย LAN พัฒนาด้วย Python และ Flask ผู้ใช้สามารถอัปโหลด ดาวน์โหลด และลบไฟล์ผ่านเว็บเบราว์เซอร์ พร้อมติดตามเครื่องที่กำลังใช้งานและดูประวัติการใช้งานได้

## Features

- **File Upload** — อัปโหลดไฟล์ผ่านเว็บ พร้อมแสดงความคืบหน้า
- **File Download** — ดาวน์โหลดไฟล์จากเซิร์ฟเวอร์
- **File Delete** — ลบไฟล์ที่ไม่ต้องการ
- **Automatic File Refresh** — อัปเดตรายการไฟล์โดยอัตโนมัติทุก 3 วินาที โดยไม่ต้อง Refresh หน้าเว็บ
- **PIN Authentication** — ต้องเข้าสู่ระบบด้วย PIN ก่อนใช้งาน
- **Online Devices** — แสดงชื่อเครื่อง IP Address เบราว์เซอร์ และเวลาเข้าสู่ระบบของเครื่องที่ออนไลน์
- **Activity Log** — บันทึกประวัติการเข้าสู่ระบบ ออกจากระบบ อัปโหลด ดาวน์โหลด และลบไฟล์
- **SQLite Database** — จัดเก็บประวัติผู้ใช้งานและกิจกรรม
- **Responsive Interface** — รองรับการใช้งานทั้งคอมพิวเตอร์และมือถือ
- **File Size Limit** — กำหนดขนาดอัปโหลดสูงสุดไว้ที่ 2 GiB ต่อคำขอ

## Requirements

- Windows 10 หรือ Windows 11
- Python 3
- เว็บเบราว์เซอร์สมัยใหม่
- คอมพิวเตอร์และอุปกรณ์ที่ต้องการแชร์ไฟล์อยู่ในเครือข่ายที่เชื่อมต่อถึงเซิร์ฟเวอร์ได้

## Installation

### 1. เปิดโฟลเดอร์โปรเจกต์

เปิด PowerShell แล้วรัน:

```powershell
cd D:\LANShare
```

### 2. สร้าง Virtual Environment

หากยังไม่มี `.venv` ให้รัน:

```powershell
py -3 -m venv .venv
```

### 3. ติดตั้ง Flask

```powershell
.\.venv\Scripts\python.exe -m pip install flask
```

### 4. ตั้งค่าตัวแปรสภาพแวดล้อม

ต้องกำหนด `LANSHARE_SECRET` และ `LANSHARE_PIN` ก่อนเริ่มเซิร์ฟเวอร์

```powershell
$env:LANSHARE_SECRET = (py -3 -c "import secrets; print(secrets.token_hex(32))").Trim()
$env:LANSHARE_PIN = "ตั้ง-PIN-ของคุณ"
```

เปลี่ยนข้อความ `ตั้ง-PIN-ของคุณ` เป็น PIN ที่ต้องการใช้จริง

**หมายเหตุ:** ควรสร้าง `LANSHARE_SECRET` ที่สุ่มอย่างปลอดภัยเพียงครั้งแรก แล้วเก็บค่าไว้ในที่ปลอดภัยเพื่อนำกลับมาใช้เมื่อเปิด PowerShell ใหม่ หากสุ่ม Secret ใหม่ทุกครั้ง session เดิมจะไม่สามารถใช้งานต่อได้

### 5. เริ่มเซิร์ฟเวอร์

```powershell
.\.venv\Scripts\python.exe app.py
```

หากเริ่มต้นสำเร็จ Flask จะรับการเชื่อมต่อผ่านพอร์ต `5000`

## Usage

### 1. ตรวจสอบ IP Address ของเซิร์ฟเวอร์

เปิด PowerShell:

```powershell
ipconfig
```

ตรวจสอบ IPv4 Address ของ Network Adapter ที่ใช้เชื่อมต่อกับอุปกรณ์อื่น

ตัวอย่าง:

```text
IPv4 Address: 192.168.1.35
```

### 2. เปิดเว็บไซต์

บนคอมพิวเตอร์ที่รันเซิร์ฟเวอร์:

```text
http://127.0.0.1:5000
```

บนอุปกรณ์อื่นในเครือข่ายเดียวกัน:

```text
http://192.168.1.35:5000
```

เปลี่ยน IP ตัวอย่างให้เป็น IP จริงของเซิร์ฟเวอร์

### 3. เข้าสู่ระบบ

กรอกชื่อเครื่องที่ต้องการแสดง เช่น:

- `PC-BANK`
- `Laptop`
- `iPhone`

จากนั้นกรอก PIN ที่ตั้งไว้ใน `LANSHARE_PIN`

### 4. แชร์ไฟล์

- เลือกไฟล์แล้วกดอัปโหลด
- กดดาวน์โหลดเพื่อรับไฟล์จากเซิร์ฟเวอร์
- กดลบเพื่อนำไฟล์ออกจากระบบ
- เปิดหน้าเว็บค้างไว้เพื่อดูการอัปเดตไฟล์และสถานะออนไลน์อัตโนมัติ

## Real-time Monitoring

หน้าเว็บเรียก API เพื่ออัปเดตข้อมูลทุก 3 วินาที โดยใช้ JavaScript `fetch()` และระบบ heartbeat

เครื่องจะถูกนับว่าออนไลน์เมื่อมีการส่งสัญญาณภายใน 45 วินาทีที่ผ่านมา

ข้อมูลที่แสดง ได้แก่:

- ชื่อเครื่องที่ผู้ใช้กรอก
- IP Address ที่เซิร์ฟเวอร์เห็น
- ข้อมูลเบราว์เซอร์
- เวลาเข้าสู่ระบบ
- ประวัติกิจกรรมล่าสุด

ชื่อเครื่องเป็นชื่อที่ผู้ใช้กรอกเอง ไม่ใช่ชื่อ Windows ที่ตรวจสอบโดยอัตโนมัติ

## Activity Log

ระบบบันทึกกิจกรรมต่อไปนี้ลงฐานข้อมูล SQLite:

| Action | Description |
|---|---|
| `login` | เข้าสู่ระบบสำเร็จ |
| `logout` | ออกจากระบบ |
| `upload` | อัปโหลดไฟล์ |
| `download` | ดาวน์โหลดไฟล์ |
| `delete` | ลบไฟล์ |

หน้าเว็บแสดงประวัติล่าสุด 40 รายการ ส่วนข้อมูลที่บันทึกอยู่ในฐานข้อมูลสามารถเก็บต่อเนื่องข้ามการรีสตาร์ตเซิร์ฟเวอร์ได้

## Troubleshooting

### เปิดเว็บจากมือถือไม่ได้

1. ตรวจสอบว่ามือถือเชื่อมต่อเครือข่ายที่เข้าถึงเซิร์ฟเวอร์ได้
2. ตรวจสอบ IP Address ด้วย `ipconfig`
3. ตรวจสอบว่า Flask ยังทำงานอยู่
4. ตรวจสอบ Windows Firewall ว่าอนุญาตการเชื่อมต่อ TCP พอร์ต 5000 จากเครือข่ายที่ต้องการ

### อัปโหลดไฟล์ไม่ได้

1. ตรวจสอบว่าเลือกไฟล์แล้ว
2. ตรวจสอบข้อความสถานะบนหน้าเว็บ
3. ตรวจสอบว่าเซิร์ฟเวอร์มีพื้นที่ดิสก์เพียงพอ
4. ตรวจสอบว่าไฟล์ไม่เกินขนาดสูงสุด 2 GiB

### รายการไฟล์ไม่อัปเดต

1. ตรวจสอบสถานะการเชื่อมต่อบนหน้าเว็บ
2. ตรวจสอบว่าเซิร์ฟเวอร์ยังทำงานอยู่
3. เปิด Developer Tools ของเบราว์เซอร์ แล้วตรวจสอบคำขอ `/api/status` และ `/api/heartbeat`

### Online Users ไม่แสดงเครื่องอื่น

ตรวจสอบว่าเครื่องอื่นเข้าสู่ระบบแล้ว และหน้าเว็บยังเปิดอยู่ หากไม่มี heartbeat เกิน 45 วินาที เครื่องนั้นจะไม่ถูกแสดงเป็นออนไลน์


- ใช้สำหรับเครือข่ายภายในที่เชื่อถือได้
- ห้ามเปิด Port Forwarding จากอินเทอร์เน็ตมายังเซิร์ฟเวอร์โดยตรง
- อย่าเผยแพร่ PIN หรือ `LANSHARE_SECRET`
- ควรอนุญาต Windows Firewall เฉพาะเครือข่ายและอุปกรณ์ที่จำเป็น
- ควรสำรองทั้งโฟลเดอร์ `storage/` และฐานข้อมูล `lanshare.db`
- เวอร์ชันนี้ใช้ HTTP ภายใน LAN จึงไม่มีการเข้ารหัสข้อมูลระหว่างทางด้วย TLS
- ควรเพิ่มการป้องกัน CSRF และการจำกัดจำนวนครั้งที่ลอง PIN ก่อนนำไปใช้งานในสภาพแวดล้อมที่มีความเสี่ยงสูง
